# 🦠 COVID-19 & Vaccination Trend Analysis Dashboard

## 📌 Project Overview

The COVID-19 & Vaccination Trend Analysis Dashboard is an interactive
Power BI project designed to analyze COVID-19 cases, reported deaths,
and vaccination trends across different countries.

The dashboard presents key performance indicators (KPIs) and data
visualizations to help users understand the progression of the pandemic
and compare vaccination coverage across countries.

## 🎯 Project Objectives

- Analyze COVID-19 case trends over time.
- Examine reported COVID-19 deaths across countries.
- Compare cumulative reported cases between countries.
- Analyze vaccine doses administered across countries.
- Compare first-dose and full vaccination coverage.
- Visualize vaccination progress over time.
- Build an interactive dashboard using Power BI.

## 🛠️ Tools and Technologies

- Microsoft Power BI Desktop
- Power Query for data cleaning and transformation
- CSV dataset
- Data visualization and exploratory data analysis
- GitHub for project version control and documentation

## 🌍 Countries Analyzed

The dashboard includes the following countries:

- India
- United States
- United Kingdom
- Brazil
- Germany

## 📊 Dashboard Features

The dashboard contains four KPI cards and six data visualizations.

### Key Performance Indicators (KPIs)

1. **Total Reported Cases** – Displays the cumulative reported case count.
2. **Total Reported Deaths** – Displays the cumulative reported death count.
3. **Total Vaccine Doses** – Displays the cumulative number of vaccine doses administered.
4. **Fully Vaccinated People** – Displays the number of people who completed the initial vaccination protocol.

### Data Visualizations

1. **COVID-19 Cases Trend** – A line chart showing reported cases over time.
2. **COVID-19 Deaths Trend** – An area chart showing reported deaths over time.
3. **Total Cases by Country** – A bar chart comparing cumulative reported cases.
4. **Vaccine Doses by Country** – A column chart comparing cumulative vaccine doses.
5. **Vaccination Coverage Comparison** – A chart comparing first-dose and full vaccination coverage.
6. **Vaccination Progress Over Time** – A line chart showing changes in vaccination coverage.

## 🎛️ Interactive Features

- Country slicer for filtering data by country.
- Date slicer for selecting a reporting period.
- Interactive charts that respond to report filters.
- KPI cards that update according to the selected filters.
